# 🤖 Robostar Robotics Cost Calculator

A simple and practical web application for estimating the cost of building a robotics project.

This tool was created as part of the **Robostar Innovations** initiative to make robotics project planning easier for students, educators, and robotics enthusiasts.

## 🚀 Features

- Calculate the estimated cost of robotics components
- Enter custom quantities for each component
- Add a project name
- View a detailed cost breakdown
- Automatically calculate the total project cost
- Reset the calculator
- Print a clean project estimate
- Responsive design for desktop and mobile devices
